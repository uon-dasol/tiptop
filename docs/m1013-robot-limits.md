# M1013 로봇 한계

## 컨트롤러 Robot Limits

티치펜던트 Workcell Manager > Robot Limits 화면 기록(2026-11-18 확인).

| 범주 | 제한 | 일반 모드 | 감소 모드 |
|---|---|---|---|
| TCP 힘 | 550 N | 550 | 72 |
| 기계적 동력 | 1600 W | 1400 | 100 |
| TCP 속력 | 8000 mm/s | 8000 | 1500 |
| 운동량 | 165 kg·m/s | 165 | 50 |
| 충돌 민감도 | 100 % | 5 | - |

| 조인트 | J1, J2 | J3 | J4~J6 | 허용치 |
|---|---|---|---|---|
| 속도 (일반·감소 동일) | 120 °/s | 180 °/s | 225 °/s | 10 °/s |

- 조인트 각도: J3 ±160°, 나머지 ±360°, 허용치 ±3° (일반·감소 동일). 매뉴얼 기본값(J2 ±95°, J5 ±135°)은 풀려 있다.
- 가속도·jerk 한계는 이 화면에 없고 드라이버·모션 코어 내부 값이다.
- 기계적 동력 1400 W는 큰 이동에서 가속도를 높이면 걸릴 수 있다(미확인). trajectory가 중단되면 티치펜던트 에러 로그를 확인한다.
- 감소 모드(동력 100 W, TCP 속력 1500 mm/s)에서는 현재 궤적이 바로 걸린다. 일반 모드로 운전하는지 확인한다.
- 충돌 민감도는 5다(매뉴얼 기본 75 %). 의도한 값인지 확인한다.

## 계획 한계

cuRobo 계획에만 쓰이며 두산 드라이버로 전달되지 않는다. 참고 문서 없이 정한 값이다.

| 항목 | 기본값 (`tiptop/robot_limits.py`의 `DEFAULTS`) |
|---|---|
| 가속도 (rad/s²) | J1~J5 5.0, J6 7.0 |
| jerk (rad/s³) | J1~J5 160, J6 224 |
| 종단 속도 허용치 (rad/s) | 0.015 |

- 값은 뷰어 실행 패널의 `로봇 파라미터`에서 바꾼다. `이 값을 기본값으로 저장`을 누르면 `tiptop/config/robot_limits.json`에 기록되어 다음 작업의 계획부터 쓰이고, 저장된 값이 없으면 `DEFAULTS`를 쓴다. `기본값으로 되돌리기`는 마지막으로 저장한 값을 불러온다.
- `tiptop/doosan/assets/m1013_uon/m1013_uon.yml`의 6개 팔 관절 가속도·jerk는 로드 시점에 이 값으로 대체된다.
- 구간 끝 잔여 속도는 관절별로 대략 `0.00154 × 그 관절의 가속도`로 늘어난다. 가속도를 올리면 종단 속도 허용치가 작으면 구간 끝 계획이 실패할 수 있다. 가속도에 맞춰 허용치도 올린다(뷰어는 자동 설정 옵션을 제공).
- 가속도가 높을수록 계획 시간은 줄지만 위 동력 한계에 걸릴 위험이 커진다.
